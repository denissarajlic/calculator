# Calculator

A simple browser calculator built to practice Git.

Each operation is developed on its own feature branch and merged into `main`.

## How to run

Open `index.html` in a browser.

## Features

- [x] Number input
- [x] Addition (`feature/addition`)
- [x] Subtraction (`feature/subtraction`)
- [x] Multiplication (`feature/multiplication`)
- [x] Expression display and operator highlight (`feature/expression-display`)
- [x] Division (`feature/division`)
- [x] Clear (`feature/clear`)
- [x] Decimal numbers (`feature/decimal`)
- [x] Backspace (`feature/backspace`)
- [x] Percent and +/- (`feature/percent-sign`)
- [x] Square root and power (`feature/sqrt-power`)
